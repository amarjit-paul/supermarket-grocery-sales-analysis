# Supermarket Grocery Sales Analysis

##  Project Overview

This project analyzes supermarket grocery sales data using Microsoft Excel to understand business performance across sales, profit, products, categories, discounts, and locations.

The analysis uses PivotTables, PivotCharts, Excel formulas, scatter plots, and trendline analysis to answer key business questions and identify areas of opportunity.

---

##  Business Questions

The analysis focuses on:

- How is the overall grocery business performing?
- Which categories contribute the most to sales?
- Which products generate the highest sales?
- Which products have high sales but comparatively lower profit margins?
- Which categories and regions generate the highest profit?
- Is there a relationship between discount and profit?
- Which locations generate the highest sales?
- Which locations have high sales but comparatively lower profit margins?

---

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Scatter plots
- Linear trendlines
- R² analysis
- Profit Margin analysis
- Sales and profitability analysis


# Key Insights

- Sales and profit show a strong positive relationship at the location level.
- Some high-sales products have comparatively lower profit margins.
- Soft Drinks is a high-sales product with a comparatively lower profit margin than other top-selling products.
- Several locations generate above-median sales while having below-median profit margins.
- Discount shows virtually no meaningful linear relationship with average profit per order in the analyzed data.
